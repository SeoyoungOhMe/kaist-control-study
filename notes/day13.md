## 1. 위치, 속도, 가속도

- 위치(x): 물체가 위치한 곳
- 속도(v): 단위시간당 위치의 변화량. 속도가 양수인 경우 위치의 변화량이 점점 커짐
- 가속도(a): 단위시간당 속도의 변화량. 가속도가 양수인 경우 속도의 변화량이 점점 커짐

### 관계식
- v = dx/dt
- a = dv/dt = d²x/dt²

## 2. 미분방정식

### 미분방정식이란?
- 어떤 값이 시간이 지나면 얼마나 변하는지 구하는 방정식. (= 미분)

### 로봇 제어에서 필요한 이유
- 로봇 제어 시, 시간이 지나면 로봇의 위치와 속도가 어떤지 예측할 수 있어야 함

### 오일러 방법
- 핵심 원리: 미래의 위치는 현재의 위치에 위치 변화량과 시간을 곱한 값을 더한 곳임
- 계산 공식: x_next = x + dx/dt * delta_t
- 시간 간격(dt)이 작아지면? dx도 작아지므로 x_next가 작아짐

## 3. 질량-스프링-댐퍼 시스템

### 구성 요소
- 질량(m): 물체의 질량
- 스프링 상수(k): 물체의 움직임을 줄여줌
- 감쇠 계수(c): 움직임을 방해함

### 운동방정식
m*x'' + c*x' + k*x = 0

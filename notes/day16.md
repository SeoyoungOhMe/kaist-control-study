
# Week 6 — 상태공간 모델 (월·화)

## 1. 상태 변수와 상태공간 모델

### 상태 변수란?
- 정의: 상태 s를 정의하는 변수로, 위치 p와 속도 v로 표현
- 상태 변수와 입력 변수의 차이: 상태 변수는 현재 상태를 나타내는 변수, 입력 변수는 결과를 바꾸는 변수

### 상태공간 모델
- 상태방정식: $\dot{x} = Ax + Bu$
- 출력방정식: $y = Cx + Du$

- 연속시간 시스템이란? 시간은 연속적이므로 연속시간 시스템으로 표현
- 상태방정식을 사용하는 이유: 상태방정식을 통해 상태의 변화 방향성을 알 수 있음

## 5. 핵심 질문

1. 왜 상태 변수로 위치와 속도를 선택할까?
   - 현재 어디있는지(위치)를 기준으로, 어느 방향으로 이동하고 있는지(속도) 알면 미래의 위치를 알 수 있기 때문

2. 왜 2차 미분방정식을 1차 방정식으로 변환할까?
   - 상태 공간 방적식 X' = Ax + Bu 로 간단하게 나타낼 수 있음.

3. A와 B의 차이는?
   - A는 현재 시스템의 움직임이고, B는 명령이 들어왔을 때의 변화

4. C와 D는 왜 필요할까?
   - C는 현재 상태 중 무엇을 보여주는지 이고, D는 명령이 출력에 더해지는 값

5. 상태공간 모델을 드론 제어에 어떻게 활용할까?
   - 현재 드론의 위치를 파악하고, 어떤 위치로 가고 싶은지 파악해서, 도달하려면 얼만큼의 힘을 줘야하는지 파악하기 용이

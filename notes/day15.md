# Week 5 — 고유값과 제어 가능성

## 1. 상태공간 방정식 복습

### 상태공간 방정식

x_dot = A * x + B * u

- 상태 변수(State): 위치와 속도 x, v로 이루어진 2차원 행렬
- 시스템 행렬 A: 현재 시스템(드론, 로봇 등)의 상태를 얼마나 어떻게 변화시킬 수 있는지 나타내는 행렬
- 입력 행렬 B: 시스템 상태를 변할 수 있게 입력하는 행렬
- 제어 입력 u: 시간에 따른 외부 입력 행렬

## 2. 고유값(Eigenvalue)

### 개념

- 고유값이란? A 행렬에서 B 행렬로 변화할 때의 크기. [1,0]에서 [2,0]으로 변화한 경우, 고유값은 2
- 고유값이 시스템의 움직임을 설명하는 이유: 움직임의 크기를 결정
- 고유값의 실수부와 허수부가 의미하는 것: 실수부는 움직임이 커지는지 작아지는지 결정(0을 기준으로), 허수부는 감쇠의 크기를 결정(위아래로 진동하는 움직임)

### 고유값과 안정성

| 고유값의 특징 | 시스템의 거동 |
|---|---|
| 실수부가 모두 음수 |움직임이 점차 작아짐 |
| 실수부가 양수인 고유값 존재 |움직임이 점차 커짐 |
| 순허수 고유값 |움직임이 그대로임 |

### NumPy 실험

- 사용 함수: `np.linalg.eigvals(A)`
- 감쇠 계수 c를 변경했을 때: c>0이면 진동 정도가 커짐, c=0이면 변화 없음, c<0이면 진동 정도가 작아짐

## 3. 제어 가능성(Controllability)

### 개념

- 제어 가능성이란? 시스템을 원하는 상태로 바꿀 수 있는지 판단하는 가능성
- 시스템이 안정적인 것과 제어 가능한 것의 차이: 안정적인 것은 시스템이 가만히 있을 때 어떻게 움직이는지에 대한 것이고, 제어 가능한 것은 원하는 상태로 바꿀 수 있는지에 대한 것임
- 드론 제어에서 제어 가능성이 중요한 이유: 제어 가능한지 먼저 알아야 제어할지 결정할 수 있음

### 제어 가능성 행렬

C=[B AB]

- B와 AB의 의미: B는 입력 행렬, AB는 시스템 행렬과 입력 행렬의 곱
- Rank란? 제어 가능한 차원의 개수
- Rank가 상태 변수 개수와 같아야 하는 이유: 상태 변수를 모두 제어 가능해야 시스템을 제어 가능하다고 할 수 있음

### NumPy 실험

- 사용 함수: `np.linalg.matrix_rank(C)`
- 제어 가능한 시스템의 Rank: Rank = 상태 변수 개수
- 제어 불가능한 시스템의 Rank: Rank < 상태 변수 개수

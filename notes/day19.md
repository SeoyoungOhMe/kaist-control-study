# Week 6 — 월요일: 피드백 제어 기초

## 1. 개루프 제어와 폐루프 제어

### 개루프 제어 (Open-loop Control)
- 정의: 항상 정해진 수식대로 행동하여, 출력을 다시 사용하지 않는 제어
- 특징: 단순함
- 단점: 외란에 잘 대응하지 못하고 정해진 수식대로만 행동함

### 폐루프 제어 (Closed-loop Control)
- 정의: 출력이 나오면, 이를 다시 입력에 사용하여 목표값과 실제값의 차이 오차를 반영하여 계산하는 제어
- 특징: feedback 방식
- 장점: 외란에 잘 대응할 수 있어 목표값과 실제값의 오차를 쉽게 줄임

## 2. 피드백 제어의 기본 구조

### 주요 개념

| 개념 | 기호 | 의미 |
|---|---|---|
| 목표값 (Reference) | r(t) |드론이 목표로 하는 높이 |
| 출력값 (Output) | y(t) |실제 드론이 위치한 높이 |
| 오차 (Error) | e(t) |목표값 - 출력값 |
| 제어입력 (Control Input) | u(t) |비례이득만큼 오차를 얼마나 반영할건지 값 |
| 비례이득 (Gain) | Kp |계산한 오차를 다음 입력에 얼마나 반영할지에 대한 비율 |

### 기본 수식

오차:
e(t) = r(t) - y(t)

P 제어:
u(t) = Kp × e(t)

### 드론 고도 제어 예시
- 목표 고도: 13
- 현재 고도: 10
- 오차: 3
- 제어입력: 0.5 * 3
- 피드백 제어 과정: 다음 고도 = 10 + 0.5 * 3

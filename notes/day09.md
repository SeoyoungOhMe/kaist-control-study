## 1. 핵심 개념

### 단일 뉴런과 MLP의 차이
- 단일 뉴런은 신경망 하나, MLP는 다중 신경망

### 순전파 → 손실 계산 → 역전파 → 가중치 갱신
- 순전파: x, w에 따라 예측값을 계산하는 과정
- 손실 계산: L = MSE(y^-y)^2 으로, 실제값과 예측값 사이의 차이 제곱의 합
- 역전파: L이 0이 되는 방향으로, w를 갱신하는 과정
- 가중치 갱신: w(new) = w - lr * (dL/dw)

### 비선형 활성화 함수가 필요한 이유
- 활성화 함수는 값이 작아졌다가 다시 커지는 비선형 그래프임. 따라서 tanh로 선형 함수에서 비선형 함수로 바꿔줌.

## 3. 직접 답하기
1. MLP에서 W1, W2는 각각 어떤 역할인가?
2. 역전파에서 연쇄법칙은 어떻게 사용되는가? w1 -> h -> w2 -> ^y -> L 이렇게 서로 영향을 주게 됨. 여기서 w1과 L의 관계를 dL/dw1 = dh/dw1 * dw2/dh * d^y/dw2 * dL/d^y 이렇게 연쇄 법칙으로 표현할 수 있음.
3. 경사하강법과 역전파의 차이는 무엇인가? 경사하강법은 최적해를 찾는 과정을 뜻함. 역전파는 경사하강법에 사용되는 과정 중 하나로, 어떤 방향으로 얼마나 가중치를 수정하면 손실이 얼마나 줄어드는지 계산하는 과정임
4. DQN에서는 왜 Q-table 대신 신경망을 사용하는가? Q-table에 모든 state를 저장하기에는 너무 저장량이 많이 필요함

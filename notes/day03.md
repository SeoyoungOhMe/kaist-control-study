# Day 03 — Linear Policy & Weight Experiment

**날짜:** 2026-10-14

## 1. 오늘의 질문

CartPole의 선형 정책에서 가중치를 변경하면 제어 성능이 어떻게 달라질까?

## 2. 실험 조건

- 환경: CartPole-v1
- 각 가중치별 30개 에피소드
- 초기 Seed: 42~71
- 평가 지표: 평균 Reward, 표준편차

## 3. 실험 결과

| Angular Velocity Weight | Mean Reward | Std |
|---|---|---|
| 0.0 |43.53 |8.38 |
| 0.1 |500.00 |0.00 |
| 0.3 |500.00 |0.00 |
| 0.5 |500.00 |0.00 |
| 1.0 |485.97 |43.21 |
| 2.0 |420.90 |125.34 |

## 4. 결과 해석

- 가장 높은 평균 보상을 보인 가중치: 0.1, 0.3, 0.5
- 가중치가 증가할 때 나타난 변화: 평균 보상이 증가하다가 꺾이고 오히려 감소함
- 가설과 달랐던 점: 성능이 제일 좋은 게 하나일 줄 알았는데 여러 가중치에 대해 성능이 동일하게 좋음
- 추가로 확인하고 싶은 부분: 0.1, 0.3, 0.5 중 어떤 게 더 나은지 판별하는 법

## 5. 선형대수

- 상태 벡터의 크기: 4
- 가중치 벡터의 크기: 4
- 내적 결과: 스칼라
- 행렬 곱셈 `(3,4) @ (4,)` 결과의 shape: `(3,)`

## 6. 네 가지 상태를 모두 활용한 정책

- 기존 정책 평균 Reward: 500.00
- 새로운 정책 평균 Reward: 500.00
- 두 정책의 차이에 대한 가설: 동일함

## 7. 오늘 배운 핵심

- 선형 정책: weight과 state를 행렬 곱셈하는 정책. np.dot(weight, state) 또는 weight @ state
- 가중치(Weight): 누적 reward를 결정짓는 중요한 변수. state와 weight를 내적하여 나온 결과가 0보다 크면 action을 1, 반대면 0으로 하는 식으로 활용
- 내적(Dot Product): np.dot 혹은 @ 로 계산
- 행렬 곱셈(Matrix Multiplication): (2,4)*(4,3) = (2,3) -> 4와 같은 내부 값은 동일해야 하며, 외부 값들로 크기가 결정됨
- 정책 파라미터를 학습한다는 의미: 누적 reward를 통해 최적의 가중치를 찾아 다음 action에 반영한다는 의미
